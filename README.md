# 🐍 The Snake - Классическая игра "Змейка"

Классическая игра "Змейка", реализованная на Python с использованием библиотеки Pygame. Проект демонстрирует объектно-ориентированный подход к разработке игр.

## 🎮 Описание игры

В игре "Змейка" игрок управляет змейкой, которая должна собирать яблоки для роста. Цель - достичь максимальной длины змейки, избегая столкновений с собственным телом.

### Особенности:
- **Бесконечные границы** - змейка может проходить через края экрана
- **Система рекордов** - отслеживание максимальной достигнутой длины
- **Настраиваемая скорость** - возможность изменения скорости игры
- **Случайные яблоки** - яблоки появляются в случайных местах, не пересекаясь с телом змейки

## 🚀 Установка и запуск

### Предварительные требования
- Python 3.7+
- pip (менеджер пакетов Python)

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск игры
```bash
python the_snake.py
```

## 🎯 Управление

- **Стрелка вверх** - движение вверх
- **Стрелка вниз** - движение вниз  
- **Стрелка влево** - движение влево
- **Стрелка вправо** - движение вправо
- **ESC** - выход из игры

## 🏗️ Архитектура проекта

### Основные классы

#### `GameObject` (Базовый класс)
- Абстрактный базовый класс для игровых объектов
- Определяет общие свойства: позиция и цвет

#### `Snake` (Класс змейки)
- Управление движением змейки
- Обработка столкновений
- Система роста и рекордов
- Логика прохождения через границы экрана

#### `Apple` (Класс яблока)
- Случайное появление на игровом поле
- Проверка на пересечение с телом змейки

## 🎨 Особенности реализации

### Система направлений
Игра использует словарь `DIC` для корректной обработки поворотов змейки, предотвращая разворот на 180 градусов.

### Обработка границ
Змейка может проходить через края экрана, появляясь с противоположной стороны.

### Система рекордов
При столкновении с собственным телом текущая длина сохраняется как рекорд, если она больше предыдущего.

## 🐛 Известные особенности

- Змейка может проходить через границы экрана (это особенность, а не баг)
- При столкновении с собой игра перезапускается автоматически
- Яблоки никогда не появляются на теле змейки
